# nori

Прототип оконного менеджера для macOS в духе [niri](https://github.com/YaLTeR/niri): окна стоят в ряд горизонтальными колонками, лента прокручивается, окно в фокусе всегда по центру экрана.

Окна двигает не Accessibility, а сам WindowServer: в Dock загружается свой dylib и плавно перемещает окна через приватный SkyLight. Поэтому анимация идёт по vsync и не зависит от приложений.

## Что умеет

- Каждое окно текущего Space — отдельная колонка. Окно в фокусе по центру, остальные слева и справа через `gap`.
- Новое окно открывается справа от окна в фокусе, лента прокручивается к нему. Закрытое окно выпадает, щель закрывается.
- Клик по окну или Cmd+Tab прокручивают ленту к этому окну.
- Окна растягиваются на всю высоту экрана, когда попадают в ленту.
- Свайп тремя пальцами по горизонтали двигает ленту за пальцами. После отрыва лента встаёт на ближайшую колонку, на краях тянется как резина. Вертикальные жесты на три пальца (Mission Control) продолжают работать.
- Окно, перетащенное мышью, после отпускания плавно возвращается в свою колонку.
- У каждого Space своя лента.
- Spaces переключаются вертикально, по той же кривой, что и окна. Любое нажатие «Переход на рабочий стол N» (клавиши, Opt+J/K, `nori-msg`) демон перехватывает: Dock переключает Space, а картинку рисует payload. Если демон выключен или упал, Dock возвращается к своей горизонтальной анимации.
- Обзор как в niri: все Spaces дисплея уменьшены и стоят столбиком, окна в них живые.

## Клавиши

| Клавиши | Действие |
|---|---|
| Ctrl+Opt+← / → | колонка левее / правее |
| Opt+H / Opt+L | колонка левее / правее |
| Opt+J / Opt+K | Space ниже / выше (через системные «Переход на рабочий стол N», они должны быть включены) |
| Opt+= / Opt+- | окно в фокусе шире / уже на `resize-step` (плавно) |
| Opt+1…5 | Space 1…5. Это системные «Переход на рабочий стол N»: демон их перехватывает и сам анимирует переход |
| Opt+O (`overview`) | обзор: все Spaces уменьшены и стоят столбиком, клик выбирает Space, Esc или Opt+O закрывает |

## Конфиг

`~/.config/nori/config`, строки `ключ = значение`, `#` начинает комментарий. Отступы в точках, по умолчанию 0. Конфиг читается при запуске, после правки демон нужно перезапустить.

Сочетания клавиш пишутся как модификаторы и одна клавиша через `+`: `option`/`alt`, `ctrl`, `cmd`, `shift` и буква или цифра (физическая клавиша US-раскладки). Без строки в конфиге действует значение по умолчанию.

```
gap = 16             # между окнами
padding-top = 40     # от строки меню
padding-bottom = 0   # от Dock / низа экрана
padding-left = 24
padding-right = 24
resize-step = 10          # шаг ширины, % ширины экрана (по умолчанию 10)
grow-width = option+=     # клавиши: модификаторы + буква, цифра, - или =
shrink-width = option+-
overview = option+o  # обзор всех Spaces
```

## Требования

macOS на Apple Silicon с ослабленной защитой. Без этого loader не сможет загрузить payload в Dock:

- SIP: Debugging Restrictions и Filesystem Protections выключены (из Recovery).
- boot-args `-arm64e_preview_abi`, иначе Dock (arm64e) не загрузит чужой dylib.
- Демону нужно разрешение Accessibility: для event tap и для ресайза окон. После пересборки macOS может спросить его заново.
- В Настройки → Трекпад → Другие жесты горизонтальный жест на три пальца («Смахивание между полноэкранными приложениями») должен быть на четырёх пальцах или выключен, иначе macOS листает Spaces вместе с лентой.
- Если стоит yabai, на время работы: `yabai -m config layout float` или `yabai --stop-service`.

## Сборка и запуск

```sh
make        # всё в build/
make run    # перезапускает Dock, загружает payload (sudo), запускает демон в терминале
```

Если менялся только демон, Dock перезапускать не нужно: Ctrl+C и `build/nori`.

## CLI

`bin/nori-msg` спрашивает запущенный демон про Spaces и окна и управляет им. Запросы отвечают JSON, удобно с `jq`. Действия при успехе ничего не печатают. При ошибке `nori-msg` пишет `error: …` в stderr и выходит с кодом 1.

```sh
nori-msg query spaces [--current]           # Spaces: номер, окна, приложения с их окнами, порядок колонок
nori-msg query windows [--space N] [--current] [--app NAME] [--id WID] [--focused]
nori-msg focus left|right                   # колонка левее / правее
nori-msg focus column N                     # колонка N на текущем Space, с 1
nori-msg focus space N                      # Desktop N через системный шорткат «Переход на рабочий стол N»
nori-msg focus window WID                   # окно по id; если оно на другом Space, сначала переходит туда

nori-msg query windows --space 2 | jq -r '.[].app'
nori-msg focus window "$(nori-msg query windows --app Telegram | jq '.[0].id')"
```

Поля окна: `id`, `pid`, `app`, `bundleId`, `title`, `space` (номер Desktop), `spaceId`, `column` (с 1, если окно в ленте), `isFocused`, `isOnScreen`, `frame`. `--app` сравнивает с именем приложения или bundle id без учёта регистра. Номера Desktop идут с 1 через все дисплеи, как в системных шорткатах. У полноэкранных Spaces номера нет, `type` у них `fullscreen`.

Заголовки окон на других Spaces видны, только если у терминала, где запущен демон, есть разрешение Screen Recording. Для окон текущего Space заголовок берётся через Accessibility.

Сокет: `/tmp/nori-ctl_$USER.socket`, доступ только у владельца. Один запрос на соединение: аргументы через табуляцию, одной строкой.

## Устройство

```
daemon/          демон на Swift, один процесс
  main.swift       event tap (клавиши, отпускание мыши), запуск, опрос окон 4 раза в секунду
  Strip.swift      лента: колонки, фокус, раскладка, резина, Spaces
  Overview.swift   обзор Spaces
  Trackpad.swift   свайп тремя пальцами из сырых касаний MultitouchSupport
  Windows.swift    список окон (CGWindowList), ресайз (Accessibility)
  Spaces.swift     Option+J/K: соседний Space через системный шорткат
  Resize.swift     Option+=/-: плавное изменение ширины окна в фокусе
  Config.swift     чтение конфига
  Payload.swift    отправка команд в payload
  Control.swift    сокет для bin/nori-msg: запросы и действия
bin/nori-msg       CLI
payload/payload.m  dylib внутри Dock: сокет, анимация окон по CVDisplayLink, вертикальное переключение Spaces
loader/loader.m    загружает payload в Dock (из yabai, MIT)
docs/PLAN.md       исходный план PoC
docs/WINDOWSERVER.md  найденное про приватные API WindowServer/Dock и как их исследовать
```

Демон шлёт в `/tmp/nori_$USER.socket` строки вида `S <wid> <x> <y>` (плавно переместить окно) или `M <wid> <x> <y>` (сразу, пока пальцы на трекпаде). Полный протокол описан в шапке `payload/payload.m`.

## Ограничения

- Одно окно на колонку, ширину колонок менять нельзя.
- Новые окна и смена фокуса обнаруживаются опросом, задержка до 0,25 с.
- Только основной дисплей.
- Исходные размеры окон после выхода не восстанавливаются.
